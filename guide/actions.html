User Guide / Built-in Actions

内置快捷动作

FlyClip 原生内置了常用的剪贴板基础操作，无需额外安装扩展即可开箱即用。

基础内置动作列表

复制 (Copy)

将选中的纯文本复制到 Windows 系统剪贴板。

剪切 (Cut)

剪切选中文本到剪贴板并从源文本区域移除（需目标输入框可编辑）。

粘贴 (Paste)

将剪贴板当前内容直接粘贴替换选区。

打开网址 (Open Link)

当选区为合法 HTTP/HTTPS 链接时智能亮起，使用系统默认浏览器秒级打开。

发送邮件 (Send Email)

当选区为电子邮箱格式时智能亮起，呼出 Windows 默认邮件客户端。

去除首尾空格 (Trim)

消除选中文本两端多余的空格与换行符并替换粘贴。

全选 (Select All)

在长按空白区域呼出的粘贴菜单中提供全选当前文档快捷操作。
