Developer Reference / Config

Config.yaml 配置文件规范

Config.yaml 是 FlyClip 扩展的核心元数据文件，定义了扩展名、图标、选项与动作。

核心字段参考表

字段名类型说明
nameString / Map扩展显示名称（必填）。支持多语言键值对 Map。
identifierString全局唯一反向域名标识符，例如 com.flyclip.extension.my-ext。
iconString图标声明。支持纯文本（如 GT）或 Iconify 图标（如 iconify:mdi:translate）。
descriptionString / Map扩展的简要功能描述。支持多语言键值对 Map。
optionsArray在设置界面中可供用户调整的参数列表。
platformsArray支持的操作系统平台：[windows, macos, linux]（默认全部支持）。
WebDAV 同步友好：跨设备同步时所有系统均允许正常安装，但在非目标系统上自动静默禁用动作，不产生阻断性错误。
actionsArray / Object定义一个或多个具体的划词动作。

多语言本地化配置 (i18n 支持)

PopClip 与 FlyClip 原生 100% 支持在 Config.yaml 中直接使用多语言字典映射配置 name（扩展名）、description（描述）、title（动作标题）以及 options[].label（设置项标签）。客户端会根据当前用户的系统/软件语言自动匹配显示（缺省回退至 en）：

# 多语言扩展声明示例
name:
  en: Case Converter
  zh-CN: 大小写转换
  zh-Hans: 大小写转换
  zh-Hant: 大小寫轉換
  ja: ケース変換

description:
  en: Convert selected text between UPPER, lower, camelCase, snake_case.
  zh-CN: 选中文本在各种大小写与命名风格之间快速转换。

identifier: com.flyclip.extension.case-converter
icon: Aa

options:
  - identifier: target_format
    label:
      en: Default Format
      zh-CN: 默认转换格式
    type: multiple
    values: [upper, lower, camel, snake]
    value labels:
      - Upper (大写)
      - Lower (小写)
      - camelCase (小驼峰)
      - snake_case (下划线)
    default value: upper

actions:
  - title:
      en: Convert to UPPER
      zh-CN: 转换为大写
    javascript: return flyclip.input.text.toUpperCase();
    after: paste-result
