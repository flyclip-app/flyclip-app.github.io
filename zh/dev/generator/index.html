🛠️ 在线扩展生成器 (Live Tool)

通过下方可视化表单快速配置并实时生成符合 FlyClip 原生规范的 Config.yaml。

在线扩展配置生成器双语与语法高亮编辑器

实时编写 JavaScript 代码，生成符合多语言规范的 Config.yaml 并一键安装

基本元信息 (支持中英文多语言)

// Convert text to uppercase

💡 JS 常用 API 说明：flyclip.input.text（选中文本）、flyclip.pressKey("ctrl c")（模拟快捷键）、flyclip.options.*（配置项）、return "结果"（配合 after: paste-result 自动替换选区）、await flyclip.fetch(url, options)（HTTP 请求）、flyclip.run(cmd, args)（唤起本地程序）。

实时生成的 Config.yaml
name:
  en: Uppercase Converter
  zh-CN: 大小写转换
description:
  en: Quickly convert selected text to uppercase
  zh-CN: 选中文本快速转换为大写
identifier: com.flyclip.extension.uppercase
icon: Aa
actions:
  - title:
      en: Uppercase Converter
      zh-CN: 大小写转换
    javascript: |
      // Convert text to uppercase
      const text = flyclip.input.text;
      return text.toUpperCase();
    requirements: [text]
    after: paste-result

提示：创建文件夹 Uppercase Converter.flyclipext/ 并将此文件保存为 Config.yaml 放入其中，即可直接作为本地扩展使用。
