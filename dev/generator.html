Developer Reference / Tool

🛠️ 在线扩展生成器 (Live Tool)

通过下方可视化表单快速配置并实时生成符合 FlyClip 原生规范的 Config.yaml。

在线扩展配置生成器Live Tool

填写表单，实时生成合规的 Config.yaml 扩展配置代码

实时生成的 Config.yaml
name: 自定义搜索
identifier: com.flyclip.extension.custom-search
description: 快速搜索选中文本
icon: iconify:simple-icons:google
actions:
  - title: 自定义搜索
    url: https://www.google.com/search?q=***
    requirements: [text]

提示：将此文件保存为 Config.yaml 放入 自定义搜索.flyclipext/ 即可立即在 FlyClip 中加载。
