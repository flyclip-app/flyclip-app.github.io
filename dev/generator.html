通过下方可视化表单快速配置并实时生成符合 FlyClip 原生规范的 Config.yaml。

💡 JS 常用 API 说明：flyclip.input.text（选中文本）、flyclip.pressKey("ctrl c")（模拟快捷键）、flyclip.options.*（配置项）、return "结果"（配合 after: paste-result 自动替换选区）、await flyclip.fetch(url, options)（HTTP 请求）、flyclip.run(cmd, args)（唤起本地程序）。

实时生成的 Config.yaml
name: 文本大写转换
identifier: com.flyclip.extension.uppercase
description: 选中文本快速转换为大写
icon: Aa
actions:
  - title: 文本大写转换
    javascript: |
      // 获取选中文本并转换为大写
      const text = flyclip.input.text;
      return text.toUpperCase();
    requirements: [text]
    after: paste-result

提示：创建文件夹 文本大写转换.flyclipext/ 并将此文件保存为 Config.yaml 放入其中，即可直接作为本地扩展使用。
