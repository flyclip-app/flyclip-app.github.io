Developer Reference / Actions

动作分类标准与开发示例

FlyClip 遵循严格的跨平台分层架构。为保证全平台一致性与轻量性能，强烈推荐优先使用 JavaScript 与 URL 动作。

零笨重依赖架构保证 (Zero Heavy Runtime)

FlyClip 绝不依赖 WebView2 (150MB+ 内存开销)，也无需用户电脑安装 Node.js。内置由 Rust 静态编译的高性能 QuickJS 引擎，冷启动耗时 < 1ms，常驻内存增量 < 1.5MB。

动作类型选型优先级

动作类型 (Type)推荐等级跨平台属性说明与开发建议
JavaScript / TS🥇 推荐首选🌐 全平台通用核心推荐。内嵌 QuickJS，支持调用跨平台本地命令与网络请求。
URL 模板动作🥇 推荐首选🌐 全平台通用适合搜索引擎、在线翻译、网页跳转等纯 Web 场景。
按键模拟 (Key Combo)🥈 次选🌐 平台通用模拟标准快捷键动作（如 ctrl c、ctrl v）。
PowerShell (.ps1)⚠️ 不推荐🪟 Windows 专属无法在 macOS/Linux 运行。仅作为 Windows 深度 API 调用的逃生通道。
Shell Script (.sh)⚠️ 不推荐🍎 macOS/Linux 专属无法在 Windows 默认运行，不具备跨平台通用性。
为什么强烈不推荐使用 .ps1 或 .sh 脚本？
  • 破坏跨平台通用性：PowerShell 在 macOS/Linux 上不可用，Bash 脚本在 Windows 上不可用，会导致扩展无法跨平台复用。
  • JavaScript 已内置跨平台本地命令调用：在 JS 中直接调用 flyclip.run("command", ["args"])，由底层 Rust 引擎统一跨平台派生子进程，一次编写处处运行！

完整扩展开发实战示例

示例 1：全平台通用 URL 搜索扩展

name: 百度搜索
identifier: com.flyclip.extension.baidu-search
description: 在百度中搜索选中文本
icon: iconify:simple-icons:baidu
actions:
  - title: 百度
    url: https://www.baidu.com/s?wd=***
    requirements: [text]

示例 2：纯 JavaScript 文本转换扩展 (推荐首选)

name: 驼峰命名转换
identifier: com.flyclip.extension.camel-case
description: 将下划线或空格文本转换为 camelCase
icon: Aa
actions:
  - title: 转换为驼峰
    javascript: |
      const text = flyclip.input.text.trim();
      return text.replace(/[-_\s]+(.)?/g, (_, c) => c ? c.toUpperCase() : "");
    requirements: [text]
    after: paste-result

示例 3：JavaScript 跨平台调用本地 CLI 命令 (flyclip.run)

直接在 JS 中调用本地外部 CLI 工具，由 Rust 宿主在各操作系统中安全派生子进程：

name: Git 状态速览
identifier: com.flyclip.extension.git-status
icon: iconify:simple-icons:git
actions:
  - title: Git 状态
    javascript: |
      // 调用本地 git 命令 (跨平台由 Rust 统一执行)
      const res = flyclip.run("git", ["status", "--short"]);
      if (res.code !== 0) {
        return `Git 错误: ${res.stderr}`;
      }
      return res.stdout.trim() || "工作区干净";
    requirements: [text]
    after: show-result

示例 4：调用本地/远程 HTTP 服务 (以 Pot Desktop & STranslate 为例)

通过 flyclip.fetch() 调用第三方本地常驻工具（如 Pot 翻译、STranslate）提供的 Local HTTP API：

name: Pot 划词翻译
identifier: com.flyclip.extension.pot-desktop
icon: Pot
options:
  - identifier: port
    label: 本地端口
    type: string
    default value: "60828"
actions:
  - title: Pot 翻译
    javascript: |
      const text = flyclip.input.text.trim();
      const port = flyclip.options.port || "60828";
      // 发送本地 HTTP 请求给 Pot Desktop
      await flyclip.fetch(`http://127.0.0.1:${port}/api/translate`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ text })
      });
    requirements: [text]

示例 5：平台标记与 WebDAV 多端同步规范 (STranslate 示例)

WebDAV 同步友好

当某个扩展关联了特定系统的专有工具（如仅 Windows 有 STranslate），声明 platforms: [windows]。通过 WebDAV 同步到 macOS/Linux 时允许安装保留配置，但在非 Windows 系统下自动静默禁用：

name: STranslate 翻译
identifier: com.flyclip.extension.stranslate
icon: ST
platforms: [windows] # 标记为仅 Windows 启用，跨端同步自动静默适配
options:
  - identifier: port
    label: HTTP 端口
    type: string
    default value: "50020"
actions:
  - title: STranslate
    javascript: |
      const text = flyclip.input.text.trim();
      const port = flyclip.options.port || "50020";
      await flyclip.fetch(`http://127.0.0.1:${port}/text?content=${encodeURIComponent(text)}`);
    requirements: [text]

示例 5：Windows 专属 PowerShell 扩展 (⚠️ 仅限特殊系统调用)

Windows-Only

仅当需要调用 Windows 原生 .NET 特有类库时使用，必须声明 platforms: [windows]：

name: Windows 原生哈希
identifier: com.flyclip.extension.win-hash
platforms: [windows]
actions:
  - title: SHA256 (PowerShell)
    shell script: |
      $bytes = [System.Text.Encoding]::UTF8.GetBytes($env:FLYCLIP_TEXT)
      $sha = [System.Security.Cryptography.SHA256]::Create().ComputeHash($bytes)
      Write-Host -NoNewline ([BitConverter]::ToString($sha).Replace('-','').ToLower())
    requirements: [text]
    after: paste-result
