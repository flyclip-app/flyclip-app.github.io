💡 Standard JS APIs: flyclip.input.text (selected text), flyclip.pressKey("ctrl c") (simulate keys), flyclip.options.* (parameters), return "result" (auto-replaces selection with after: paste-result), await flyclip.fetch() (HTTP fetch), flyclip.run() (native sub-process).

name:
  en: Uppercase Converter
  zh-CN: 大小写转换
description:
  en: Quickly convert selected text to uppercase
  zh-CN: 选中文本快速转换为大写
identifier: com.flyclip.extension.uppercase
icon: Aa
actions:
  - title:
      en: Uppercase Converter
      zh-CN: 大小写转换
    javascript: |
      // Convert text to uppercase
      const text = flyclip.input.text;
      return text.toUpperCase();
    requirements: [text]
    after: paste-result

Tip: Create folder Uppercase Converter.flyclipext/ and save this content as Config.yaml to test locally.
