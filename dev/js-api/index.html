Developer Reference / JavaScript Runtime

JavaScript API Reference Manual

FlyClip features a high-performance QuickJS engine statically embedded with Rust (fully supporting modern ES2020 syntax). This manual documents all global host objects, built-in functions, configuration parameters, and real-world code examples.

QuickJS Performance: Sub-millisecond cold start · Zero external dependencies · Native cross-platform
ES2020 Full Standard

1. Global Host Objects

When executing JavaScript actions, FlyClip automatically injects global namespaces, supporting both flyclip and popclip as bidirectional equivalent aliases:

Property / MethodTypeDescription
flyclip.inputObjectObject containing the currently selected text and regex extractions.
flyclip.optionsObjectKey-value dictionary of user preferences configured for this extension.
flyclip.copy(text) / copyText(text)FunctionWrites the specified string to the system clipboard.
flyclip.paste(text?) / pasteText(text?)FunctionSimulates Ctrl+V to paste into current focus (or writes text first if provided).
flyclip.readClipboard()FunctionReads and returns current plain text from the system clipboard.
flyclip.openUrl(url)FunctionOpens the specified URL in the default system browser.
flyclip.showText(text)FunctionDisplays a notification toast / result banner on the floating palette.
flyclip.pressKey(combo)FunctionSimulates hardware keyboard shortcuts (e.g. "ctrl c").
flyclip.run(cmd, args)FunctionSynchronously runs a local executable CLI tool and returns { stdout, stderr, code }.
flyclip.fetch(url, opts)FunctionPerforms async HTTP/HTTPS requests with custom timeout and body options.
flyclip.processstringProcess name of the active foreground window (e.g. "chrome.exe").
flyclip.actionIdentifierstringIdentifier of the specific action clicked.

2. Selection Input (flyclip.input)

  • flyclip.input.text: Currently selected text (or regex-matched substring if regex is specified).
  • flyclip.input.matched: Equivalent alias for text.
  • flyclip.input.fullText: Full raw selected string before regex extraction.
// Example: Get selected text and convert to uppercase
const text = flyclip.input.text;
return text.toUpperCase();

3. Extension Parameters (flyclip.options)

When options are declared in Config.yaml, user configurations are automatically populated in flyclip.options:

// Read configured prefix and port
const prefix = flyclip.options.prefix || ">>";
const port = flyclip.options.port || "50020";

return prefix + " " + flyclip.input.text;

4. Keyboard Simulation (flyclip.pressKey)

Dispatches hardware-level keystrokes to the focused window. Returns true on success.

Signature: flyclip.pressKey(combo: string): boolean

Supported Key Combos:

"ctrl c" // Copy
"ctrl v" // Paste
"ctrl shift f" // Global Search
"alt f4" // Close Window
"enter" / "escape" // Enter / Esc
"wait 50" // 50ms pause

5. Run Native Commands (flyclip.run)

Spawns a native sub-process via the Rust host layer synchronously to run local CLI utilities and capture stdout/stderr without requiring await.

Signature: flyclip.run(command: string, args?: string[]): { stdout: string, stderr: string, code: number }
// Example: Run git status and capture output
const res = flyclip.run("git", ["status", "--short"]);
if (res.code !== 0) {
  return "Git error: " + res.stderr;
}
return res.stdout.trim() || "Working tree clean";

6. HTTP Network Requests (flyclip.fetch)

Perform async HTTP/HTTPS requests to local daemon APIs (e.g. STranslate on port 50020, Pot Desktop on port 60828) or remote web endpoints.

Signature:
flyclip.fetch(url: string, options?: {
  method?: "GET" | "POST" | "PUT" | "DELETE" | "HEAD",
  headers?: Record<string, string>,
  body?: string,
  timeout?: number    // Milliseconds (default: 10000)
}): {
  status: number,
  statusText: string,
  ok: boolean,
  data: string,
  text(): string,
  json(): any
}
// Example: Call Pot Desktop Local API
const text = flyclip.input.text.trim();
const port = flyclip.options.port || "60828";
const res = await flyclip.fetch(`http://127.0.0.1:${port}/api/translate`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text }),
  timeout: 5000
});
if (res.ok) {
  return res.json().result || "No translation";
}
